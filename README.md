# DropRandomizer

A Minecraft Paper plugin project that randomizes block drops and crafting results. The detailed project documentation is in [DropRandomizer/README.md](DropRandomizer/README.md).

The Maven project is under `DropRandomizer/`. With Java 21 and Maven installed, build it with:

```bash
cd DropRandomizer
mvn clean package
```

The JAR is written to `DropRandomizer/target/`.
